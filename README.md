# Aventurao

Projeto de jogo point-and-click feito em Adventure Game Studio.

O jogo acompanha Gabriel, 9 anos, num dia que devia ser normal mas deixa rapidamente de o ser. A primeira area jogavel e o quarto de Gabriel, com puzzles de exploracao, objetos escondidos, inventario e humor em primeira pessoa.

## Por onde recomecar noutro PC

1. Instalar Adventure Game Studio 3.6.2 ou versao compativel.
2. Abrir `Game.agf` no AGS Editor.
3. Confirmar que o jogo abre a sala 1 e que o personagem jogavel e `cChar1` / Gabriel.
4. Ler a documentacao em `docs/` antes de alterar scripts.

## Estado atual resumido

- Motor: Adventure Game Studio.
- Nome do jogo: `Aventurao`.
- Resolucao: 800x600.
- FPS: 40.
- Estilo de fala: LucasArts.
- Primeira sala: quarto de Gabriel.
- Interface principal: verb coin com `Olhar`, `Falar`, `Usar` e `Pegar`.
- Puzzle principal implementado: preparar/usar a pistola de Nerfs para fazer cair a partitura, por a partitura no tripe e praticar oboe antes de dormir.
